YallahSir – AI Tourism Platform
Plateforme intelligente de tourisme qui aide les voyageurs à découvrir des destinations et à organiser leurs voyages grâce à l'intelligence artificielle.
Fonctionnalités
- Recommandation de destinations.
- Chatbot touristique basé sur l'IA.
- Recommandation d'itinéraires avec K-Means.
- Gestion des avis et des favoris.
Technologies utilisées
- Backend : Node.js, Express.js
- Base de données : MongoDB
- IA : Gemini API, K-Means
- Frontend : HTML, CSS, JavaScript
- Cartographie : Leaflet
Installation
git clone URL_DU_PROJET
cd YallahSir
npm install
npm start
